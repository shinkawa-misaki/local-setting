# local-setting
Local environment construction tool by bash-oo-framework

# 構成
```
.
├── localSetting.sh
├── README.md
└── src
    └── app
        ├── commands
        │   ├── alias.sh
        │   ├── docker.sh
        │   ├── modules
        │   │   └── template.sh
        │   ├── ssh.sh
        │   ├── toolInstall.sh
        │   ├── toolUninstall.sh
        │   ├── upgrade.sh
        │   └── zsh.sh
        └── lib
            ├── Array
            │   └── Contains.sh
            ├── oo-bootstrap.sh
            ├── util
            │   ├── exception.sh
            │   └── type.sh
            └── util_ext
                ├── alias.sh
                ├── log.sh
                ├── providers.sh
                └── zsh.sh
```
